Reason for Choosing the Project

We chose the Multi-Client Chatting Platform because it provides a practical way to understand and implement important concepts of Computer Networks. The project allows us to work with TCP sockets, client-server communication, concurrent connections, data transmission, and synchronization. It is also relatively easy to demonstrate and explain while providing enough scope to implement networking concepts in a meaningful way.

Features of the Final Project

The final project will include the following features:

- A TCP-based client-server architecture.
- Multiple clients can connect to the server simultaneously.
- A separate thread will handle each connected client.
- Clients will be able to send and receive messages.
- The server will manage communication between connected clients.
- Proper synchronization/mutex mechanisms will be used to handle shared resources.
- The system will handle client connection and disconnection.
- Messages will be transmitted reliably using TCP.
- A simple and user-friendly interface will be provided for chatting.

The project will demonstrate how multiple users can communicate through a centralized server while applying fundamental Computer Networking concepts in a practical application.
